# Индекс pre-commit checks (`ai_checks_pre_commit`)

```yaml
artifact_id: ai-checks-pre-commit-index
artifact_type: ai-check-index
owner_layer: .ai/checks/pre-commit/
checks:
  - .ai/checks/pre-commit/CHECK-DELIVERY-COMMIT-SCOPE.md
```

## Назначение

Индекс проверок перед commit. Для delivery commit/push используется:

- `.ai/checks/pre-commit/CHECK-DELIVERY-COMMIT-SCOPE.md`
