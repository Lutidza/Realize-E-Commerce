# SRP Utilities

- Версия: 1.0.0
- Дата обновления: 2026-03-02

Утилиты в директории `src/RealizeCore/srp` помогают UI-слою работать с
фасетами Search Profile и строить ссылки SRP без знания низкоуровневых
деталей маршрутизации. Они не занимаются парсингом URL — за это отвечает
фабрика `createSearchRoute` из `src/RealizeCore/routes/srp`.

## Состав пакета

- **`srpSelections.ts`** — типы и нормализация выборок фасетов
  (`SrpSelection`, `AttributeSelectionsRecord`). Используется при сборке
  фильтров и вычислении выбранных значений на клиенте.
- **`srpFacetConfig.ts`** — хелпер `buildFacetConfigMap`, который строит
  карту конфигураций фасетов из `ResolvedSearchProfile`.
- **`srpFacetDictionary.ts`** — функции работы со словарём alias → facet
  (`groupFacetDictionaryByAttribute`).
- **`buildSrpHref.ts`** — сборка SRP-ссылок на основе текущего
  `SrpRouteMatch`, выборок пользователя и словаря фасетов. Внутри
  переиспользует `createSearchRoute`, чтобы гарантировать единый формат
  пути для всех коллекций.
- **`srp.index.ts`** — публичный экспорт утилит, подключаемый через
  `@/RealizeCore/srp`.

## Зависимости и принципы

- Все функции ожидают `ResolvedSearchProfile` и словари, полученные через
  `src/RealizeCore/routes/shared/facets`, поэтому сначала нужно разрешить
  профиль (например, `getResolvedProfileForCollection`) и только потом
  использовать утилиты.
- `buildSrpHref` требует валидного профиля: если профиль `null`, сначала
  нужно загрузить/кешировать его на уровне страницы.
- При добавлении новых коллекций или изменении профилей достаточно
  обновить `ResolvedSearchProfile`; SRP-утилиты автоматически подхватят
  изменения (slug, набор фасетов и т.д.).

## Добавление новых утилит

1. Сохраняйте номинование в стиле `srp*.ts`, чтобы по имени файла было
   ясно назначение (`srpFacetConfig`, `srpSelections`).
2. Все комментарии должны быть в формате Typedoc, как указано в
   `docs/AI_INSTRUCTION.md`.
3. При необходимости расширения API обновляйте `srp.index.ts`, чтобы
   экспорты оставались централизованными.
